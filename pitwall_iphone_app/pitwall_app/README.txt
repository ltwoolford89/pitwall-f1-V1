PITWALL — F1-inspired iPhone web app (first working version)

Files to publish: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.

INSTALL USING ONLY AN IPHONE
1. In Safari, go to github.com and create a free account or sign in.
2. Create a new PUBLIC repository, for example: pitwall-app.
3. Choose Add file > Upload files. Browse to the unpacked pitwall_app folder in iPhone Files and upload all five app files. Commit changes.
4. Go to repository Settings > Pages, choose Deploy from a branch, branch main and / (root), then Save.
5. When GitHub displays the published address, visit https://YOUR-USERNAME.github.io/pitwall-app/ in Safari.
6. Tap Share, then Add to Home Screen, then Add.

IMPORTANT
- The app is a website installed as a Home Screen shortcut/PWA, not an App Store app.
- It does not use a private or official F1 API. It reads publicly available standings and race data through free unofficial Jolpica and OpenF1 APIs, with a data snapshot fallback.
- Some third-party API connections may be blocked, delayed or change in the future. The snapshot was sourced on 8 October 2026 and will become out of date when offline.
- F1 session schedules should always be checked against the official schedule for late changes.
- Predictions are an entertainment-only heuristic, not guaranteed results or wagering advice.
- Kayo button opens Kayo's official homepage; sign-in/subscription may be necessary.
- Game contracts and money are entirely simulated; no real payments or jobs are offered.
- Career progress is stored on your device in browser storage; clearing website data may erase it. Make backups before switching devices.
- GitHub Pages public repositories are visible to anyone; do not add passwords or private information.

Developed as an independent fan project. Not affiliated with Formula 1, FIA or Kayo.
